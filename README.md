# JavaScript Practice

A collection of JavaScript learning exercises covering core language concepts, DOM manipulation, browser events, API requests, and small interactive projects.

## Topics and examples

- **Core JavaScript / ES6:** scope, types, callbacks, closures, hoisting, arrays, objects, classes, and common array methods.
- **DOM and events:** selecting and updating elements, event listeners, bubbling, delegation, and simple UI interactions.
- **Working with APIs:** fetching JSON data, handling responses, and rendering API data in the browser.
- **Mini projects:** includes a Payoo-style mobile financial services interface and other practice pages.

Folder names are retained as they appear in the repository, so use the directory tree to locate a particular exercise.

## Run an exercise

Most examples are plain HTML and JavaScript:

1. Clone or download this repository.
2. Open the relevant exercise folder.
3. Open its HTML file in a browser, or use VS Code with a local development server.
4. For API examples, an internet connection may be required.

There is no single build command because the repository contains independent exercises rather than one application.

## Purpose

This is a learning archive, not a production-ready application. Some exercises may be incomplete or depend on external APIs and assets.
